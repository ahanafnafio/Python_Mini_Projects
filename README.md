# Python Projects & Utilities Lab

A modular collection of standalone Python scripts, automation tools, network utilities, and mini-applications. This repository serves as a personal laboratory for experimenting with Python libraries, APIs, and everyday scripting solutions.

 📂 Repository Structure

Each directory contains an independent script or mini-tool designed to run in isolation:

| Directory | Description | Key Modules / APIs |
| :--- | :--- | :--- |
| `BOT_main.py` | Interactive terminal chatbot utilizing the Gemini API | `google-genai` |
| `IP_address_main.py` | Command-line utility to resolve domain hostnames to IP addresses | `socket` |
| `Location_main.py` | IP geolocation lookup tool reporting city, region, and country | `requests`, `ipinfo.io` |
| `Website_main.py` | Living Portfolio about myself | `requests`, `ipinfo.io` |
